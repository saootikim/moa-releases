# Moa 설치 파일

친구들끼리 쓰는 채팅·음성 앱 Moa의 설치 파일을 올려 두는 곳이다. 소스 코드는 여기에 없다.

## Windows에 설치하기

1. [최신 설치 파일 받기](https://github.com/saootikim/moa-releases/releases/latest) 에서 `Moa-Setup-<버전>.exe`를 받는다.
2. 실행한다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누른다. 설치 파일에 유료 서명이 없어서 뜨는 경고다.
3. 설치 위치를 고르고 설치한다. 관리자 권한은 필요 없다.
4. Moa를 열고 **계정 만들기**로 가입한다. 인증 메일의 링크를 누른 뒤 로그인한다.
5. 서버에 들어가려면 **＋ → 초대 코드**에 받은 코드를 넣는다.

처음 통화할 때 마이크 사용을 물으면 허용한다.

새 버전이 나오면 앱이 알아서 받아 두고, 다시 시작할 때 설치한다.

지우려면 Windows 설정 → 앱 → 설치된 앱에서 Moa를 제거한다.

## Android에 설치하기

1. 폰에서 [최신 Release](https://github.com/saootikim/moa-releases/releases/latest)를 열고 `Moa-<버전>.apk`를 받는다.
2. 받은 파일을 연다. "출처를 알 수 없는 앱" 경고가 뜨면 이 앱(브라우저나 파일 앱)의 설치를 허용한다.
3. 설치한 뒤 Moa를 열고 로그인한다.

Android 앱에는 음성 통화와 푸시 알림이 아직 없다. 자동 업데이트도 없어서 새 버전은 다시 받아 설치한다.
